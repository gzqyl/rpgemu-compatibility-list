## 📖 仓库简介

本仓库是 **RPGEmu 游戏兼容性白皮书** 的开源数据库与静态托管主页。旨在为玩家提供公开、透明的游戏运行帧率、插件兼容情况及不同 iOS 设备上的真实测试数据。

---

## 🤝 如何参与贡献

我们非常欢迎社区玩家提交您的测试结果！如果您在 RPGEmu 上测试了某款 RPG Maker 游戏，可以通过以下方式帮助更新列表：

1. **提交 Issue**：前往 [Issues](../../issues) 页面，按照模版填写：游戏名称、引擎类型、运行帧率/状态、测试机型。
2. **提交 Pull Request (PR)**：
   - Fork 本仓库。
   - 直接修改 `index.html` 中的表格，添加您的测试条目。
   - 提交 PR 并注明您的测试设备与运行表现。
