## 📖 Overview

This repository serves as an open-source database and host for the **RPGEmu Game Compatibility List**. Its purpose is to provide users with transparent performance benchmarks, plugin compatibility reports, and device-specific test results before running their favorite RPG Maker games.

---

## 🤝 How to Contribute

We welcome game compatibility reports from the community! If you've tested a game on RPGEmu, please help us expand the list:

1. **Submit an Issue**: Click on the [Issues](../../issues) tab and submit your test report (include Game Title, Engine Type, FPS/Status, and Device Model).
2. **Submit a Pull Request**:
   - Fork this repository.
   - Edit the `index.html` table directly to add your test entry.
   - Submit a PR with a brief note on your testing environment.
